Реестр контактов

Веб-приложение для управления списком контактов, разработанное в рамках тестового задания.

----------------------------------------------------------------------
Технологический стек

Фронтенд: React, TypeScript, Vite, React Hook Form, Zod, TanStack Query.
Бэкенд: Node.js, Express, TypeScript.
Стили: Нативный CSS (без применения сторонних UI-библиотек).
Хранение данных: In-memory массив на бэкенде + `localStorage` для клиентских черновиков.

--------------------------------------------------------------------

Инструкция по запуску

Для запуска проекта вам потребуется открыть **два независимых окна или вкладки терминала** (например, Git Bash).

Запуск бэкенда

1. Перейдите в папку бэкенда:
   	cd backend
2. Установите зависимости:
	npm install
3. Запуск сервера разработки:
	npm run dev

Запуск фронтэнда

4. Перейдите в папку фронтэнда:
	cd frontend
5. Установите зависимости:
	npm install
6. Запуск сервера разработки:
	npm run dev
Откройте полученную ссылку (обычно http://localhost:5173)

Основной функционал:
1. Таблица и сортиовка: Просмотр списка контактов с колонками(фио, компания,статус, дата создания). Поддержка индикаторов направления
2. Поиск: мнгновенная фильтрация по фио, компании,статус, даты создания
3. Модальные окна и url: открытые карточки синхронизуются с адресной строкой браузера.
4.  Автосохранения черновиков: все несохранённые изменения автоматически сохраняются в localStorage, при повторном открыти появляется баннер восстановления с возможностью очистки
5. CRUD операции: создание, редактирование, удаление
